# Ollama 模型參數基準表

狀態：已套用。本表供人工檢閱；參數會依任務強度動態解析，呼叫端明確指定的值可在模型安全上限內覆寫。

- [`config/ollama-model-parameters.json`](config/ollama-model-parameters.json) 是不可修改的唯讀基礎層，永遠先套用。
- [`config/ollama-model-parameters.dynamic.json`](config/ollama-model-parameters.dynamic.json) 是可修改的動態覆寫層，只需填入要變更的欄位。
- 執行時以「基礎層 → 動態層」合併；動態層未指定的欄位回退基礎值。

## 動態模式

動態檔預設啟用 `task_random`：以任務內容雜湊與任務強度做可重現的加權選擇。相同任務可重現，困難任務固定使用品質模式。

| 模式 | 目標 | 主要策略 |
| --- | --- | --- |
| `maximum_speed` | 最大化速度 | 4K～16K Context、短輸出、Thinking 關／低 |
| `maximum_quality` | 最大化品質 | 使用模型困難 Context、較長輸出、Medium／High Thinking |
| `maximum_efficiency` | 最大化效益 | 平衡速度、記憶體與品質 |
| `task_random` | 依任務選擇 | 輕量偏速度、普通偏效益、中級偏品質、困難固定品質 |

若所選動態模式已實際推論失敗，Qwen3.8 27B 參數裁決角色只允許做出「臨時回復唯讀基礎預設」的決定。系統以原模型重試一次，不自由生成參數、不寫回基礎檔或動態檔，也不遞迴重試。

## 動態套用規則

| 任務強度 | Context | 預設輸出 | 預設 Thinking |
| --- | --- | ---: | --- |
| 輕量 | 最多 8K | 256 | 關 |
| 普通 | 模型日常值 | 512 | Low |
| 中級 | 模型困難值 | 768 | Medium |
| 困難 | 模型困難值 | 1K | High，並由第二模型複核 |

- Flash Attention：開。
- KV Cache：`q8_0`（Ollama 對 Q8 的實際環境變數值）。
- 官方／內建 generation config 欄位不送出覆蓋值。
- 明確請求的輸出長度會受各模型上限約束；Context 仍按實際輸入量自適應，不會為短輸入無條件配置到上限。
