# 模型對話 1.0

模型對話是只在主系統中具有獨立清單項目與生命週期的介面，集中提供本機模型對話、使用者教學，以及由 Ollama 本機模型訓練星澄的受治理入口。
實體程式位於 `local-model/model-dialogue`；模型清單、路由、設定、權限、記憶、訓練資料與推論服務全部由 `local-ai` 平台共用。介面不建立自己的業務層或資料庫，也不直接存取模型權重，所有請求皆透過治理驗證的 AI 通道送出。

教學樣本會先經星澄的內容、事實與品質檢查，再寫入可版本化、可回復的本機學習層。
選取「星澄」時，對話會依使用者當次指令讀取星澄自身主資料庫的已核准記憶、訓練成果與能力編成資料；平台媒介可保存本次連續性紀錄，但不會讀寫投資資料庫或各 Ollama 模型的專屬資料庫。訓練路徑固定為 `model-dialogue -> local-ai -> Ollama loopback -> 星澄品質閘門 -> 星澄原生資料庫`，不使用外部 AI。
此介面維持 1.0，且設定為 source-only，不建立獨立打包檔。
