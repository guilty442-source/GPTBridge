# AI投資管家 4.0

Project ID: `ai-assistant`

AI投資管家現在只保留本地輔助 AI 與投資分析功能。外部 AI 協作、AI 名單、群組詢問與共享記憶已拆到 `platform_tools/ai-collaboration`。

## 功能邊界

- Excel / CSV / JSON 持股匯入與自製表格掃描；`.xlsx` 支援一般列式表格、橫向多工作表，以及「報酬」彙總表。工作表、資料列、代號、名稱、市場、資產類型、數量、成本、幣別與配息欄位均可預覽及手動調整。
- 使用者來源檔一律禁止鎖檔：Windows 以讀、寫、刪除全共享方式短暫讀入記憶體，關閉來源後才解析，背景工作只使用解析結果。
- 本機持股明細可手動新增、修改與確認刪除，包含配息金額、單位配息、月配息、年化配息率、回本率及 TWD 現值，保留修訂版號與稽核紀錄，不回寫來源 Excel。
- 配息以每週 TWD 為預估標準；台股、ETF 與美股可用外網配息事件更新，並依事件間隔自動辨識每週、雙週、每月、雙月、每季、半年、每年或不定期；共同基金查不到外網資料時保留 Excel 基準值。
- 匯率以華南銀行即期買賣中價為 TWD 評價基準，保存買入、賣出、估值匯率、來源與生效時間。
- 前端以狀態版本進行每秒輕量同步；盤中報價只會在台股、港股或美股各自的正常交易時段自動抓取，並自動處理港股午休與美股夏令時間。
- 新組合匯入後會在背景補齊缺少的公開資料，包括名稱、商品類型、交易幣別、最新價格、配息頻率與來源；既有 Excel 或手動值優先，不以網路資料覆蓋。
- 本金分為原始金額、本金幣別與 TWD 換算值；原幣成本完整保留，TWD 本金使用華南銀行估值匯率計算。
- 本地 AI 指令錯誤會自動寫入 `runtime/local-ai-errors.jsonl`，回應會附可追查的錯誤代碼，敏感欄位會遮蔽。
- 本地輔助 AI 提供可追溯的風險代理、資料覆蓋率、反證條件與模擬方案；不輸出無證據的方向評等，也不會自動下單。
- 股價與持倉風險監測。
- 本地 AI 命令欄。
- 手機遠端同步預設關閉；明確啟用後預設只監聽 `127.0.0.1:18765`。區網監聽必須再次確認，跨網路橋接只接受 HTTPS。一次性配對碼只用來換取有到期、閒置期限與 IP 綁定的工作階段權杖。
- 本地診斷預設只匯出去識別 JSON；包含持倉或財務明細的完整報告必須再次確認，且只能匯出加密 `.ivault`。

## 2.0 十項升級

1. 完整交易帳本：買賣、股息、費用、入出金、FIFO 已實現損益、費稅與交易更正/刪除。
2. 歷史時序資料庫：SQLite WAL 儲存行情、組合快照、部位快照與資料健康狀態。
3. 績效歸因：未實現/已實現損益、股息、TWR、XIRR、權益曲線與幣別歸因。
4. 專業組合風險：年化波動、Beta、VaR、CVaR、最大回撤、相關性、曝險與風險貢獻。
5. 壓力測試與回測：市場衝擊情境、買入持有、等權重、動能策略、費用/滑價與無前視保護。
6. 再平衡模擬：現金保留、單一部位上限、最低交易額與預估費用；只產生草案，不自動下單。
7. 事件與新聞情報：Yahoo 歷史行情、股息/拆股、新聞情緒，以及手動財報/總經行事曆。
8. 持久警示：價格、集中度、VaR、回撤、事件窗口、冷卻去重與確認狀態。
9. AI 決策日誌：保存證據、信心、接受/拒絕/執行狀態、30 日結果與 Brier Score 校準。
10. 專業工作台與安全：五分頁桌面/手機介面、Windows DPAPI、敏感欄位保護、配對期限、撤銷、速率限制與安全標頭。

## 3.0 十項升級

1. 多幣別會計：預設以 TWD 顯示，採華南銀行牌告匯率，保留原始幣別並拆分資產/匯率損益。
2. 券商對帳：CSV、TSV、XLSX 與文字型 PDF，比對差異後由使用者確認才入帳；來源檔仍以短暫快照讀取且不鎖 Excel。
3. 獨立背景排程：後端週期同步行情、外匯、公司行動、警示、通知與每日備份，不依賴工作台保持開啟。
4. 進階配置：風險平價、最小變異、最大夏普、Black-Litterman 與 CVaR，支援單檔與換手率上限。
5. 因子與績效歸因：市場、規模、價值、動能、品質代理因子與標的貢獻。
6. 蒙地卡羅與市場狀態：可重現的情境路徑、終值分布、虧損機率、回撤與多空/盤整/高波動辨識。
7. 公司行動治理：股息、拆股、更名、合併、下市與基金配息的驗證、去重、資料品質問題及人工覆核。
8. 風險事件中心：本機/行動通知佇列，Windows、Email、Teams、Slack 預設停用，明確同意後才可啟用。
9. 模型治理：模型與提示版本、輸入輸出雜湊、資料來源、評估紀錄、Brier 校準及品質不佳時唯讀降級。
10. 全庫安全：SQLite 僅在記憶體執行，落盤以 Windows DPAPI 全庫保護，具換鑰、加密備份、完整性驗證、還原前備份與稽核日誌。

## 4.0 可靠性與安全升級

1. 本地 AI 獨立可信度模型：缺資料回傳 `unavailable`，不再用假中性分；規則分只標示為非方向性的 `heuristic_risk_proxy`。
2. 研究評分必須同時具有來源、資料日期、標準化分數與數值證據；回答只能引用穩定 evidence ID，數字與證據不一致時安全拒答。
3. 本機模型只允許 loopback 端點與已安裝模型，不會自動下載；提供 compact、balanced、quality 與自動硬體設定檔。
4. 校準改用結構化方向、期限與門檻；持有/監控不算方向命中，重複樣本去重，樣本數不足不會鎖定模型。
5. 回測以單位數及自然權重漂移計算，納入初始/再平衡成本、核准公司行動、共同日期覆蓋率與限制揭露。
6. 風險貢獻改用共變異數 Euler MRC；資料不足時明示 current-weight proxy，不偽裝成完整歷史估計。
7. 狀態與分析資料使用 profile 隔離、單一程序 owner lock、原子落盤、完整性雜湊、損壞恢復及具 manifest 的備份。
8. 手機同步改為明確啟用、安全配對與工作階段權杖；同步採三方合併，保留人工修改及刪除，不復活舊持倉。
9. 投資政策可設定目標、期限、風險承受力、現金需求與禁止資產；再平衡仍只產生模擬草案，不會自動下單。
10. EXE 封裝驗證來源與 payload 摘要、排除執行期資料、辨識後端擁有者並顯示啟動錯誤，避免新舊程式互相誤殺或靜默混用。

所有投資分析均為本地輔助資訊，不構成投資建議。回測與再平衡結果不會送出任何交易。

## Renderer 合成視覺 Smoke

執行 `npm.cmd run smoke:ai-assistant-ui` 會先建置 AI 投資管家 renderer，再以本機 Playwright Chromium 和完全合成的投資資料檢查：

- 桌面與手機版水平溢位。
- 七個工作台分頁、ARIA tab/tabpanel 關聯與方向鍵操作。
- 表單標籤、按鈕名稱、表格標題、重複 ID、主標題與主要 landmark。
- 瀏覽器 console、未捕捉例外與失敗資源請求。
- 主要桌面、配置、自動化、安全及手機畫面截圖。

報告與截圖寫入 `test-results/ai-assistant-visual/`，不讀取或保存真實持股。

## 封裝 EXE Playwright 與 axe Smoke

執行 `npm.cmd run smoke:ai-assistant:visual` 會用官方 Playwright Electron API 啟動實際封裝的 `dist/ai-assistant.exe`，並在啟動前驗證 package payload 與來源版本。這項測試不需要另外執行 `playwright install`，因為它直接使用 EXE 內附的 Electron runtime。

測試會建立一次性的 `APPDATA`、`LOCALAPPDATA`、`TEMP`、IPC 與投資資料目錄，停用本地模型、手機同步及外部行情金鑰，不會讀取真實投資資料。完成後只會使用該 sandbox 內通過 tool ID、路徑、package digest 與 shutdown token 驗證的 owner descriptor 關閉測試後端，再刪除自己建立的暫存目錄。

檢查範圍包含：

- packaged runtime、版本、preload bridge、context isolation 與 renderer sandbox 邊界。
- 後端成功連線、七個主要分頁、ARIA 關聯、方向鍵、Home 與 End 操作。
- 主程序與 renderer console、未捕捉例外、失敗請求及 renderer crash。
- 每個分頁的 WCAG A/AA axe 掃描、ARIA snapshot 與 PNG 截圖。

後端固定使用 `127.0.0.1:8765`。若執行前該連接埠已被其他程序占用，測試會安全標記為 skipped、附上唯讀程序診斷並要求先關閉擁有該連接埠的 GPTBridge runtime；測試不會終止、附加或重用未知程序。

Playwright 結果寫入 `test-results/ai-assistant-visual/`，HTML 報告寫入 `playwright-report/ai-assistant/`。可用 `npx.cmd playwright show-report playwright-report/ai-assistant` 查看。

## 不包含

- ChatGPT、Claude、Gemini、Grok、DeepSeek 外部 AI 群組協作。
- 外部 AI 登入頁開啟。
- 協作任務看板。

這些功能請從獨立的 `AI協作工具` 啟動。
